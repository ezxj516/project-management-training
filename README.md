# 项目负责人培训材料

## 培训主题

**如何当好地质项目负责人**

## 核心原则

1. **进度第一**：按时完成项目，延期即违约
2. **质量第一**：成果过硬，质量是生命线
3. **安全第一**：野外作业风险多，人员安全是底线
4. **规范第一**：严格按照规范要求工作

## 培训材料列表

### 1. 30分钟演讲稿
- **文件**：`演讲稿-30分钟.md`
- **时长**：30分钟
- **字数**：约5000字
- **结构**：开场+5个主要部分+结语
- **重点**：进度与质量、角色定位、核心能力、项目管理实战、沟通协调、职场生存

### 2. 45分钟PPT大纲
- **文件**：`PPT大纲-45分钟.md`
- **页数**：25页
- **时长**：45分钟
- **结构**：封面+目录+7个主要部分+结语
- **重点**：角色认知、核心能力、项目管理实战、地质灾害责任、沟通协调、职场生存、AI辅助工具

## 主要内容

### 角色定位
- 项目负责人是"帅"不是"将"
- 四个第一：进度、质量、安全、规范
- 出了问题不要自己扛

### 核心能力
- 五层金字塔：价值观→专业知识→沟通协调→资源整合→战略思维

### 项目管理实战
- 踏勘铁律
- 五控管理
- 达标则收
- 地质灾害终身负责

### 沟通协调
- 例会制度
- 领导不配合的应对
- 不帮出馊主意

### 职场生存
- 权限边界
- 自保防线
- 三阶段进阶

## 使用建议

1. 根据实际情况调整内容和时间
2. 关键金句加粗，方便记忆
3. 结合实际案例讲解
4. 互动环节可以穿插在各个部分
